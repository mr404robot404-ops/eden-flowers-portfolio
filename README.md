# Eden Flowers

Портфолио проекта Eden Flowers 0.9.3-beta — сайта цветочного магазина.

Сайт: [eden-flowers.kg](https://eden-flowers.kg)

## Возможности

- Каталог цветов и композиций
- Оформление и управление заказами
- Административная панель

## Технологии

React · TypeScript · Node.js · Express · MongoDB · Cloudinary · Nodemailer

Этот публичный репозиторий содержит только описание проекта. Исходный код приложения, ключи, пароли и данные клиентов здесь не размещены.
